# הבית הדיגיטלי של פרויקט (פיילוט קשרי דיירים, אקו סיטי)

אב־טיפוס להמחשה. המפה הרגילה (`/maps/eco-city-demo/`) לא משתנה. הפיילוט נטען רק מכתובת עם `?pilot=<שם>`.

| כתובת | מה נפתח |
|---|---|
| `/maps/eco-city-demo/home/` | כתובת השיתוף (וואטסאפ). מציגה תצוגה מקדימה ומעבירה ל-`?pilot=demo&src=share` |
| `/maps/eco-city-demo/?pilot=demo` | המפה בתצוגה הרגילה, עם סמן "פרויקט ההדגמה" וכפתור בפס. הבית הדיגיטלי נפתח רק בלחיצה עליהם |
| `/maps/eco-city-demo/` | המפה הרגילה, כמו קודם |

## הקבצים
- `pilot.js`: קורא את `pilot/<שם>.json`, בודק ומנקה את התוכן, מצייר סמן וכפתור בפס, ובונה את הבית בתוך כרטיס הפרויקט הקיים.
- `pilot.css`: העיצוב, בצבעים ובגופנים של המפה.
- `demo.json`: תוכן לדוגמה. אין בו פרויקט, אנשים, תאריכים או התחייבויות אמיתיים.
- `../home/index.html` ו-`../home/preview.jpg`: כתובת השיתוף ותמונת התצוגה המקדימה.
- ב-`../index.html` יש שתי נקודות חיבור, שפועלות רק כשיש `?pilot=` בכתובת.
- בדיקות: `node tools/test-eco-city-pilot.mjs` משורש המאגר (Playwright).

## מבנה קובץ התוכן
כל השדות רשות, חוץ מ-`project.name`, `project.lat` ו-`project.lng`. חלק בלי תוכן לא מוצג.

- `demo`: `true` מציג את הפס "אב־טיפוס להמחשה — לא פרויקט אמיתי". בפרויקט אמיתי: `false`.
- `project`: `name`, `city`, `place` (שורה מתחת לשם), `description`, `infoStatus` (למשל "מידע מאושר"), `updated` (`YYYY-MM-DD`), `hero.image` (קובץ מ-`characters/` או `photos/` בלבד), `hero.caption`.
- `stages`: `title`, `items` (עד 6 שלבים), `current` (מספר השלב, מ-0, או `null` כשאין שלב מאושר), `note`.
- `updates[]`: `date`, `status` (`approved` מוצג "מאושר", כל ערך אחר מוצג "כפוף לאישור"), `title`, `body`, `links[]` (`label`, `url`).
- `faq[]`: `q`, `a`.
- `contacts[]`: `role`, `text`, ולא חובה: `url` ו-`label`. אין לכתוב פרטים של אדם בלי אישור שלו ושל אקו סיטי.
- `links[]`: קישורים רשמיים (`label`, `url`).
- `meetings[]`: `date`, `time`, `title`, `place`, `registration` (קישור), `approved`. מפגש מוצג רק עם `"approved": true` ורק עד התאריך שלו.
- `inquiry.mode`: `off` (מוסתר), `preview` (תצוגה של הטופס, השדות כבויים ושום דבר לא נשלח), או `link` עם `url` לערוץ מאושר וקיים של אקו סיטי.

כל קישור חייב להיות `https://`. קישור אחר פשוט לא מוצג. כל טקסט מוצג כטקסט, גם אם יש בו תגיות.

## פרויקט אמיתי, כשייבחר
1. מעתיקים את `demo.json` לקובץ חדש בשם הפרויקט, באותיות לטיניות קטנות, ספרות ומקפים (למשל `bnei-dan-54.json`).
2. ממלאים רק תוכן שאקו סיטי אישרה בכתב, ומשנים `demo` ל-`false`.
3. בודקים בתצוגה מקדימה: `?pilot=bnei-dan-54`.
4. לכתובת שיתוף משלו: מעתיקים את `home/` לתיקייה חדשה, ומעדכנים בה את הכתובת, התגיות והתמונה.

## עדכון תוכן
צוות קשרי הדיירים שולח טקסט מאושר. עושים קהילה מעדכנים את קובץ ה-JSON ב-PR, מריצים את הבדיקות וממזגים. GitHub Pages מעלה את השינוי תוך דקות.

## פריסה וחזרה אחורה
- פריסה: מיזוג ל-`main`. GitHub Pages מפרסם את התיקייה כמו שהיא.
- חזרה אחורה: `git revert` של קומיט המיזוג ודחיפה ל-`main`. אפשר גם רק למחוק את קובץ התוכן: בלי קובץ הפיילוט לא נטען, והמפה עובדת כרגיל.

## מה אין כאן
אין שרת, טופס שנשלח, מסד נתונים, התחברות, קוקיז או מדידה. שירות פניות אמיתי דורש פיתוח נפרד ואישור (ראו את הביקורת הטכנית).
